# Android 客户端测试指南

## 🎯 测试目标

测试 Android 原生客户端的核心功能：
1. **设备绑定** - 绑定到 SNET 服务器
2. **加入网络** - 加入现有网络 W4NSYT6E

---

## 📋 准备工作

### 在 Mac 客户端获取测试信息

#### 步骤 1：获取设备授权码

**方法 A：使用现有配置**
1. 打开 Mac SNET 客户端
2. 点击右上角"设置"
3. 查看"服务器地址"和"设备 ID"
4. 如果已绑定，记录当前配置

**方法 B：重新绑定**
1. 在 Mac 客户端中点击"设置"
2. 点击"绑定设备"
3. 输入服务器地址：`https://snet.uizhi.eu.org:8090`
4. 输入授权码（需要从服务器管理员获取）
5. 记录生成的设备 ID

---

#### 步骤 2：获取网络邀请信息

**加入现有网络 W4NSYT6E**

1. 打开 Mac SNET 客户端
2. 找到网络"W4NSYT6E（诗迪网络）"
3. 点击网络卡片右上角的"⋮"菜单
4. 选择"邀请成员"
5. 复制以下任一信息：
   - **邀请链接**：`snet://join?nid=W4NSYT6E&code=XXXXX`
   - **配对码**：显示的配对码

---

## 📱 Android 客户端测试

### 测试 1：设备绑定

1. **打开 Android SNET 应用**
   - 观察启动速度（应 <1秒）
   - 查看初始界面

2. **点击右上角"⋮"菜单**
   - 选择"绑定设备"

3. **输入绑定信息**
   - 服务器地址：`https://snet.uizhi.eu.org:8090`
   - CA 证书：留空（使用默认）
   - 设备授权码：从 Mac 客户端或管理员获取

4. **点击"绑定"**
   - 观察绑定结果
   - 查看设备 ID 是否显示

5. **验证绑定**
   - 查看顶部设备信息卡片
   - 确认服务器地址显示
   - 确认"已绑定"状态

---

### 测试 2：加入网络

**方法 A：使用邀请链接**

1. **点击右上角"⋮"菜单**
   - 选择"加入网络"

2. **粘贴邀请链接**
   - 格式：`snet://join?nid=W4NSYT6E&code=XXXXX`
   - 点击"加入"

3. **验证加入**
   - 查看网络列表
   - 确认 W4NSYT6E 网络显示
   - 检查网络状态

**方法 B：手动输入网络信息**

1. 如果没有邀请链接，可以手动创建网络进行测试
2. 点击菜单 → "创建网络"
3. 输入网络名称和子网

---

### 测试 3：网络操作

1. **连接网络**
   - 切换网络开关到"开启"
   - 观察 VPN 状态变化
   - 查看连接状态

2. **断开网络**
   - 切换网络开关到"关闭"
   - 观察断开状态

3. **刷新状态**
   - 点击顶部刷新按钮
   - 查看网络列表更新

## 🐛 问题排查

### 绑定失败
- 检查服务器地址是否正确
- 检查授权码是否有效
- 检查网络连接

### 加入失败
- 检查邀请链接格式
- 检查配对码是否过期
- 检查是否已绑定设备

### VPN 连接问题
- 检查 Android VPN 权限
- 检查网络是否已连接
- 查看 VPN 状态图标
