## 🔍 测试步骤

### 第一步：启动测试

1. **打开应用**
   - 记录启动时间
   - 观察是否有黑屏/白屏
   - 查看初始界面

2. **检查设备信息**
   - 设备 ID 是否显示
   - 状态是否显示
   - 服务器地址是否显示

### 第二步：绑定测试

1. **打开绑定对话框**
   - 点击右上角菜单
   - 点击"绑定设备"

2. **输入绑定信息**
   - 服务器地址：`https://snet.uizhi.eu.org:8090`
   - 设备授权码：[从服务器或管理员获取]

3. **执行绑定**
   - 点击"绑定"按钮
   - 观察绑定结果
   - 检查设备 ID 是否显示

### 第三步：创建网络测试

1. **打开创建对话框**
   - 点击菜单 → "创建网络"

2. **输入网络信息**
   - 网络名称：[自定义]
   - 子网：`10.88.0.0/24`

3. **创建网络**
   - 点击"创建"按钮
   - 观察创建结果
   - 检查网络是否出现在列表

### 第四步：加入网络测试

1. **打开加入对话框**
   - 点击菜单 → "加入网络"

2. **输入邀请信息**
   - 方式 1：粘贴邀请链接
   - 方式 2：输入网络 ID + 配对码

3. **加入网络**
   - 点击"加入"按钮
   - 观察加入结果
   - 检查网络是否出现在列表

### 第五步：网络操作测试

1. **网络开关**
   - 切换网络开关
   - 观察连接状态变化
   - 检查 VPN 图标状态

2. **网络详情**
   - 点击网络卡片
   - 查看网络信息
   - 查看成员列表

3. **刷新状态**
   - 点击刷新按钮
   - 观察列表更新

### 第六步：删除/退出测试

1. **删除网络（owner）**
   - 点击删除按钮
   - 确认删除
   - 检查网络是否移除

2. **退出网络（member）**
   - 点击退出按钮
   - 确认退出
   - 检查网络是否移除
