## 🎯 Phase 1: 核心功能（P0）

### 1.1 VPN 服务集成 ⚡

**目标**: 实现完整的 VPN 连接功能

**实现步骤**:
1. 集成现有的 `SnetVpnService`
2. 添加 VPN 权限请求流程
3. 实现 VPN 连接状态管理
4. 添加 VPN 状态指示器

**工作量**: 4小时

---

### 1.2 加入网络功能 ⚡

**目标**: 实现通过链接或邀请码加入网络

**功能**:
- 输入邀请链接（snet://join?nid=xxx&code=xxx）
- 输入邀请码
- 扫码加入（二维码）

**实现步骤**:
1. 创建加入网络对话框
2. 解析邀请链接/邀请码
3. 调用 `SnetBridge.joinNetwork()`
4. 集成扫码功能

**工作量**: 3小时

---

### 1.3 设备授权 ⚡

**目标**: 实现设备绑定和授权流程

**功能**:
- 设备授权码输入
- 服务器绑定
- 设备 ID 显示

**实现步骤**:
1. 创建授权对话框
2. 实现服务器绑定流程
3. 调用 `SnetBridge.bind()`
4. 显示设备 ID 和状态

**工作量**: 3小时

## 🎨 UI 设计原则

### **与 Mac/Windows 客户端保持一致**

1. **布局结构**:
   - 顶部: 标题栏 + 状态指示器
   - 中间: 网络列表/详情
   - 底部: 操作按钮

2. **配色方案**:
   - 背景: 深色主题 (#0A0E14)
   - 主色: 蓝色 (#1E88E5)
   - 文字: 浅灰色 (#ECEFF1)

3. **交互方式**:
   - 点击: 查看详情
   - 长按: 显示菜单
   - 滑动: 刷新

## 🔧 技术实现

### **架构**:
- **UI 层**: Jetpack Compose
- **业务层**: ViewModel + Repository
- **数据层**: SnetBridge (Go JNI)

### **状态管理**:
- StateFlow: 响应式数据流
- Coroutines: 异步操作
- LiveData: UI 状态更新

### **导航**:
- Compose Navigation
- 单 Activity 架构
